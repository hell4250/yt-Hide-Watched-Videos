YouTube - Hide Watched Videos

YouTube 피드에서 이미 시청한 동영상을 자동으로 숨겨주는 Tampermonkey 유저스크립트입니다.



시청 진행률이 설정값 이상인 영상은 바로 안 보이게 처리합니다.

기능



홈 피드, 검색 결과, 구독 피드, 재생목록 등에서 시청한 영상 숨김

시청 진행률(progress bar) 기준으로 판단 (기본 15% 이상)

YouTube가 동적으로 콘텐츠를 추가해도 실시간으로 적용

한 번 검사한 영상은 다시 검사하지 않음



설치 방법



Tampermonkey 확장 프로그램을 설치합니다.

Tampermonkey 대시보드에서 새 스크립트 만들기를 선택합니다.

기존 코드를 전부 지우고, 이 저장소의 스크립트 코드를 붙여넣습니다.

저장(Ctrl+S)합니다.

YouTube를 새로고침하면 바로 동작합니다.



설정

스크립트 상단의 값만 바꾸면 됩니다.

JavaScriptconst WATCHED\_THRESHOLD = 15;  // 이 퍼센트 이상이면 숨김

원하는 수치로 변경한 뒤 저장하세요.



예: 50으로 바꾸면 절반 이상 본 영상만 숨깁니다.

동작 방식



영상 썸네일에 있는 시청 진행 바(width: N%)를 읽어서 진행률을 계산합니다.

진행률이 WATCHED\_THRESHOLD 이상이면 해당 영상 컨테이너에 display: none을 적용합니다.

MutationObserver로 새로 추가되는 영상을 감지해 처리합니다.

progress bar가 나중에 붙는 경우도 상위 컨테이너를 찾아 다시 검사합니다.



지원 페이지

https://www.youtube.com/\* 전체에서 동작합니다.



홈, 검색, 구독, 채널, 재생목록 등 주요 피드에 적용됩니다.

주의사항



YouTube UI가 크게 바뀌면 셀렉터가 동작하지 않을 수 있습니다. 그때는 스크립트 업데이트가 필요합니다.

이미 로드된 영상 중 progress bar가 아직 렌더링되지 않은 경우는 숨기지 못할 수 있습니다.

@grant none으로 작성되어 있어 외부 API나 저장소를 사용하지 않습니다.
